# NZ- and Māori-specific APA 7 formatting

Standard APA 7 guidance (as trained into most models) covers journal articles and books well but is silent or wrong on several source types NZ students hit constantly. This file covers those gaps. It assumes the source has already passed the verification protocol in SKILL.md — this file is about formatting, not verification.

## Macrons and te reo Māori

- Preserve macrons (tohutō) exactly as they appear in the original source — over a, e, i, o, u (ā, ē, ī, ō, ū). Never strip them for convenience, and never guess where one belongs if the source you found doesn't show one clearly; check the official source (e.g., the author's own institutional page, or a NZ government/iwi site) rather than assuming.
- Māori words are not italicised in NZ academic convention the way "foreign" words are in generic APA — most NZ university style guides (Otago, Auckland, AUT, Massey) explicitly say te reo Māori terms should NOT be italicised, since Māori is an official language of Aotearoa New Zealand, not a foreign language. Follow this unless the student's own institution's guide says otherwise.
- When citing an author with a Māori name, use their name exactly as they publish it — do not anglicise or drop macrons.

## Iwi, hapū, and Māori organisations as corporate author

When a source is authored by an iwi, hapū, rūnanga, or Māori trust rather than an individual, treat that entity as the corporate author, same as you would a government department:

```
Ngāi Tahu. (2023). Title of report. Publisher.
```

If the work is a pūrākau (traditional narrative) or mātauranga Māori source attributed to an iwi or hapū rather than a named individual, cite the iwi/hapū as author and note the nature of the source in the reference if the original does (e.g., a specific pukapuka or wānanga publication).

## Waitangi Tribunal reports

Format as a report by a government-established body:

```
Waitangi Tribunal. (Year). Title of report (Report No. if given). Author. URL if publicly available
```

Waitangi Tribunal reports are usually available directly on the Ministry of Justice / Waitangi Tribunal website — verify via that site specifically rather than a secondary summary.

## NZ legislation

APA 7 legal citation for NZ statutes follows this pattern:

```
Title of Act Year (NZ), s [section number if relevant).
```

Example: `Privacy Act 2020 (NZ), s 22.`

For Bills (not yet enacted), name it as a Bill and include its year and reading status if relevant to the point being made. Always verify current legislation against the official New Zealand Legislation website (legislation.govt.nz) — Acts get amended, and a section number found in an older secondary source may no longer match the current Act.

## Stats NZ, government departments, and Crown entities

Treat the department/entity as corporate author, same pattern as Waitangi Tribunal:

```
Stats NZ. (Year). Title of report. Author. URL
Ministry of Education. (Year). Title of report. Author. URL
```

Where a report has both a named Crown entity and an individual author clearly credited on the title page, prefer the individual as author with the entity as publisher, matching standard APA 7 practice for organisational reports with named authors.

## Institution-specific style variations

Otago, Auckland, AUT, Massey, Victoria University of Wellington, Canterbury, and Lincoln each publish their own APA 7 addenda (usually via their library site) that can differ in small ways — most commonly around italicisation of Māori terms, treatment of iwi sources, and reference list ordering conventions. If the student names their institution, search for "[institution name] APA 7 referencing guide" and check the current version rather than assuming it matches what's written here — these guides get updated, and this file is not a substitute for the student's actual current library guide when there's a conflict.
